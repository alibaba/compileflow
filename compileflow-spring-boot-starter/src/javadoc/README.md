# CompileFlow Spring Boot Starter

This artifact is a format-neutral dependency-only Spring Boot starter and exposes no Java API. Add one or more
CompileFlow frontend modules, or use a format-specific CompileFlow Spring Boot starter.

Use the public API from `compileflow-api`. Configuration keys and extension contracts are documented in the
[CompileFlow documentation](https://github.com/alibaba/compileflow/tree/master/docs/en).
